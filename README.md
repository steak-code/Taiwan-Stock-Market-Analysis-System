# 📈 台股 AI 分析系統

> 使用 LSTM 深度學習模型，預測台股隔日收盤價  
> 並提供 RSI、MACD、MA20 等技術指標與回測圖表，協助使用者判斷趨勢。
>
> ⚠️ **本專案僅供學習與研究使用，預測結果不構成投資建議。**

---

## ✨ 功能總覽

### 1. 查詢分析
- 輸入 4 碼台股代碼，例如 `2330` 台積電，自動抓取近 1 年股價
- 支援 `.TW`（上市）與 `.TWO`（上櫃）自動切換
- 若股票已下市或代碼錯誤，會顯示「找不到股票，可能已下市」，不會給假預測

### 2. AI 預測
- 使用 LSTM 模型，輸入過去 60 天資料，預測明天收盤價
- 預測目標為「漲跌幅」，而非「價格」，避免模型偷懶猜「明天跟今天一樣」
- 預測結果會顯示為「▲ 預測漲 0.40%（8.34 元）」，% 在前面，幾元在後面當參考

### 3. 技術指標 KPI 卡片
| 指標 | 說明 | 判讀 |
| :--- | :--- | :--- |
| **RSI (14)** | 相對強弱指標 | > 70 過熱，< 30 超賣 |
| **MACD** | 趨勢動能 | > 0 多頭，< 0 空頭 |
| **MA20** | 20 日均線 | 價格站上 MA20 偏多，跌破偏空 |
| **明天預測** | LSTM 預測價格 | 顯示預測漲 / 跌幾 %，並顯示漲停 / 跌停價 |

### 4. 視覺化圖表
- **主圖**：近 60 天收盤價 + MA20 + 明天預測點
- **回測圖**：模型預測 vs 實際價格，兩條線越接近，代表模型越準

### 5. 模型表現評估
- **MAPE**：平均絕對百分比誤差，平均每次預測差幾 %
- **天真預測 MAPE**：猜「明天跟今天一樣」的誤差，作為基準線
- **方向準確率**：猜對「明天漲或跌」的機率，比 MAPE 更重要
- **風險提示**：根據 MAPE + 方向準確率，自動顯示 ✅ / ⚠️ / ❌

### 6. 使用者體驗
- **熱門股票一鍵查詢**：2330、2317、2454、2303、2881、2412
- **查詢歷史**：使用 Session 記錄最近 8 筆查詢，點一下就能再查
- **載入動畫**：第一次訓練模型需 20-40 秒，會顯示「正在分析中...」，不會以為當機
- **複製結果**：一鍵複製結果
- **手機版適配**：KPI 卡片自動變 2x2，不會爆版

## 🧠 模型設計與優化

這是本專案最核心的部分，經過多次優化，解決了初版的 5 個問題，以及後期抓到的 2 個嚴重 Bug。

### 初版問題 → 優化後

| 問題 | 影響 | 優化方法 |
| :--- | :--- | :--- |
| **1. 資料外洩** | `Scaler` 用全部資料來算，偷看未來，MAPE 看起來很漂亮，但上線會變差 | `Scaler` 只用訓練集來 `fit`，測試集只能 `transform` |
| **2. 預測價格** | 模型會偷懶，猜「明天跟今天一樣」就已經很準 | 改成預測「漲跌幅」，例如 +2%，模型必須真的學趨勢 |
| **3. 沒有正規化** | 訓練 30 次一定過擬合，記住訓練資料 | 加入 `Dropout(0.2)` + `EarlyStopping(patience=10)`，沒進步就自動停 |
| **4. 只用 4 個特徵** | 模型看不懂台股 | 擴充到 11 個特徵，包含 RSI、MACD、MA5/20/60、乖離率、成交量變化、布林帶寬度 |
| **5. 只算 MAPE** | MAPE 低不代表能賺錢，猜對方向更重要 | 新增「方向準確率」與「天真預測 MAPE」，跟亂猜比較 |

### 模型架構

```text
輸入：過去 60 天 x 11 個特徵
  ↓
LSTM (64) + Dropout(0.2)
  ↓
LSTM (32) + Dropout(0.2)
  ↓
Dense (16, relu) + Dropout(0.1)
  ↓
Dense (1) -> 輸出明天漲跌幅
```

- **Loss**：`Huber`，比 `MSE` 更不怕極端值（例如突然漲停）
- **Optimizer**：`Adam`
- **漲跌幅限制**：`clip(-0.1, 0.1)`，台股漲跌停 10%，超過就砍掉，不讓模型亂猜 20%
- **訓練 / 測試切分**：85% 訓練，15% 測試
- **固定種子**：`random.seed(42)` + `np.random.seed(42)` + `tf.random.set_seed(42)`，讓每次訓練結果都一樣，不會一下 28%，一下 42%

## 🔧 特徵工程

| 特徵 | 來源 | 用途 |
| :--- | :--- | :--- |
| `Close` | Yahoo Finance | 收盤價 |
| `Volume` | Yahoo Finance | 成交量 |
| `RSI` | `ta` 套件 | 相對強弱 |
| `MACD` / `MACD_Signal` | `ta` 套件 | 趨勢動能 |
| `MA5` / `MA20` / `MA60` | 滾動平均 | 短、中、長期均線 |
| `BIAS20` | (Close - MA20) / MA20 | 乖離率，超漲超跌 |
| `Daily_Return` | `pct_change()` | 今天漲幾 % |
| `Volume_Change` | `pct_change()` | 成交量放大還是縮小 |
| `BB_Width` | 布林帶 | 盤整還是要噴 |
| `Target` | `Close.shift(-1) / Close - 1` | 明天漲跌幅（預測目標） |

## 🛡️ 防 Inf 處理

`pct_change()` 在成交量為 0 時會產生 `inf`，導致 `MinMaxScaler` 報錯：

```text
Input X contains infinity or a value too large for dtype('float64')
```

修法：
```python
# 1. Volume 的 0 先換掉
df['Volume'] = df['Volume'].replace(0, np.nan).ffill().fillna(1)
# 2. 分母加 1e-8，不會除以 0
df['BIAS20'] = (df['Close'] - df['MA20']) / (df['MA20'] + 1e-8)
# 3. 限制範圍
df['Daily_Return'] = df['Close'].pct_change().clip(-0.2, 0.2)
# 4. 最後全部清掉 inf
df = df.replace([np.inf, -np.inf], np.nan).dropna()
```

## 🐛 本專案抓到的 2 個嚴重 Bug

這部分是本專案最有價值的經驗，不是只有「做出來」，而是「抓到錯在哪」。

### Bug 1：漲跌停 Bug — 預測價超過漲停

**現象：**
```text
目前 86.20 元，明天預測 98.88 元，▲ 預測漲 12.68 元
台股漲跌停只有 10%，86.20 的漲停是 94.82，98.88 已經超過漲停，不可能發生
```

**原因：**
舊模型是預測「價格」，新程式以為模型是預測「漲跌幅」。  
舊模型輸出 `98.88`，被當成漲跌幅 `98.88`，再去乘 `86.20`，就爆掉了。  
而且 `models/` 裡面還留著舊的 `.h5`，沒有刪掉。

**修法：三層保險**
1. `model.py` 加入 `MODEL_VERSION = "v2_return"`，舊模型版本不對，自動作廢重訓
2. 預測完再 `clip(-0.1, 0.1)`，漲跌幅超過 10% 就砍掉
3. `stock_analysis.py` 再 `clip(current * 0.9, current * 1.1)`，價格絕對不能超出漲跌停

**修完：**
```text
目前 86.20，預測漲跌幅 2.43%，預測價 88.29，漲停 94.82，跌停 77.58
```

### Bug 2：差一天 Bug — 用昨天預測今天，假裝是預測明天

**現象：**
```text
網頁：目前 86.20 元，預測 94.08 元
終端機：目前 95.70 元，預測 94.08 元
兩個「目前價格」不一樣
```

**原因：**
```python
df['Target'] = df['Close'].shift(-1) / df['Close'] - 1
df = df.dropna()  # 最後一天的 Target 是 NaN，會把今天整天刪掉
```

`_add_features` 裡面的 `dropna()` 會把今天刪掉，模型以為的「最後一天」是昨天 95.70，它預測的 94.08 其實是「今天」，不是「明天」。

**修法：訓練跟預測分開**
```python
# 訓練用的 df，要把最後一天 (Target 是 NaN) 拿掉
df_train = df.dropna(subset=['Target']).copy()
# 預測用的 df，要留著最後一天 (今天)
df_all = df.copy()

# 訓練切分用 df_train
split_index = int(len(df_train) * 0.85)

# 明天預測要用 df_all 的最後 60 天，包含今天
last_60 = scaler.transform(df_all[feature_cols].values[-SEQ_LEN:])
last_price = float(df_all['Close'].iloc[-1])  # 今天的價格，不是昨天的
```

**修完：**
```text
[DEBUG] df_all 最後一天: 2026-11-19 Close=2100.00 (今天)
[DEBUG] df_train 最後一天: 2026-11-18 Close=2175.00 (昨天)
[INFO] 2330 目前 2100.00，預測漲跌幅 0.40%，預測價 2108.34，漲停 2310.00，跌停 1890.00
```

**影響：**
修掉這個 Bug 後，2330 的方向準確率從 66.67% 掉到 42.86%。  
之前 66% 是因為模型在偷看今天，修好之後才是真正預測明天的成績。

## 📊 回測結果

> 測試時間：2026-11-19，測試集為最近 15% 資料（約 28 天）  
> 比較基準：天真預測 = 猜「明天跟今天一樣」，完全不用模型  
> 重要：以下為修復「差一天 Bug」後的真實成績，不是修復前的假成績

| 股票 | 模型 MAPE | 天真預測 MAPE | 誰贏？ | 方向準確率 | 評價 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **2330 台積電** | 1.74% | **1.66%** | ❌ 亂猜贏 | 42.86% | 模型輸了，比丟硬幣還差 |
| **2317 鴻海** | **1.97%** | 2.01% | ✅ 模型贏一點點 | **57.14%** | 普通，但有贏 |
| **2303 聯電** | 3.73% | **3.25%** | ❌ 亂猜贏 | 53.57% | 模型輸了，但方向有猜對一半以上 |
| **3624** | 6.54% | **5.61%** | ❌ 亂猜贏 | 28.57% | 下市股，資料異常，不應使用 |

### 結論

- **修復差一天 Bug 前**：2330 方向準確率 66.67%，看起來很厲害，但其實是資料外洩，模型在偷看今天。
- **修復差一天 Bug 後**：2330 方向準確率 42.86%，比隨機猜測 50% 還低，證明之前的 66% 是假的。
- **整體結論**：LSTM 在預測台股隔天漲跌上，並沒有明顯優於天真預測。台股短期走勢接近隨機漫步，單靠歷史股價難以穩定獲利。
- **3624 不應納入評比**：Yahoo 回傳 `possibly delisted; no price data found`，且一天從 95.70 跌到 86.20，資料已斷裂，方向準確率 28.57% 是資料異常造成的。

### MAPE 判讀標準

| MAPE | 意思 |
| :--- | :--- |
| < 1% | 太好，好到不正常，99% 是資料外洩 |
| **1% - 3%** | **很好，權值股常見範圍** |
| 3% - 5% | 正常，大部分台股 LSTM 在這裡 |
| 5% - 8% | 普通，小型股、波動大 |
| > 10% | 很差，跟亂猜差不多 |

| 類別 | 技術 |

| **圖表** | Matplotlib |

### 效能優化

- **模型快取**：第一次查詢會訓練並存成 `models/2330.h5`，第二次查詢直接從硬碟載入，不用重訓，從 30 秒變 2 秒。
- **模型版本控制**：`MODEL_VERSION = "v2_return"`，只要改模型架構，就改版本號，舊模型自動作廢。
- **股價快取**：`lru_cache(maxsize=32)`，避免重複抓 Yahoo Finance。
- **圖檔不互相覆蓋**：檔名加入時間戳 `2330_20261119_180101.png`，不會被上一支股票的圖蓋掉。
- **Flask 不重複訓練**：`app.run(debug=True, use_reloader=False)`，不然 debug 模式會開兩個進程，訓練兩次。

## ⚠️ 已知限制

1. **只預測隔天**，不預測長期趨勢，長期預測誤差會放大。
2. **未考慮漲跌停、除權息、法說會等事件**，突發新聞會導致預測失準。
3. **高波動股表現較差**，例如 2303 聯電，MAPE 會輸給天真預測。
4. **模型為單一股票訓練**，每支股票都要各自訓練一個模型，無法跨股票通用。
5. **資料來源為 Yahoo Finance**，若 Yahoo 延遲或缺資料，可能抓不到。
6. **已下市股票會抓不到資料**，例如 3624，Yahoo 會回傳 `possibly delisted`，應直接顯示錯誤，不要給假預測。
7. **修復差一天 Bug 後，方向準確率回歸真實**，不再是之前 66% 的假準確率，LSTM 在隔天預測上並沒有明顯優勢。
